# 동원HUB Android
Android 8 이상용 업무 웹 연동 앱입니다. 패키지 `kr.co.ipharmkorea.dongwonhub`, 버전 1.0.0 / 10000. OTP 로그인, 파일 선택, 뒤로 가기와 새로고침을 지원합니다. 웹에서 생성하는 Blob/CSV 파일은 PC 웹에서 내려받습니다. 오프라인 업무와 네이티브 백그라운드 푸시 알림은 포함되지 않았습니다.
시작 및 로그인 완료 시 새 APK를 확인합니다. 자동 다운로드 후 SHA-256·패키지·버전·동일 서명키를 확인하며 Android의 설치 확인을 표시합니다.
`build.sh`는 API 35 및 build-tools 35.0.0, JDK 17을 사용합니다. 최초 APK와 같은 서명키로 새 APK를 제작해야 하며 키는 저장소에 올리지 않고 소유자용 백업으로 보관합니다. GitHub Actions는 서명 없는 APK만 제작하고 키는 업로드하지 않습니다.
